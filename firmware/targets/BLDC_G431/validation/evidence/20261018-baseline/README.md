# G431 基础验证照片摘选

这里保留 4 张原始示波器照片，供核对基础验证中的关键读数。文件逐字节复制，未裁剪、旋转、压缩或标注；复制前后 SHA256 与原记录一致。来源、镜像哈希、设置、读数和限制见 [index.json](index.json)。

共同条件为 12 V / 50 mA 电源限流设置、无电池、电机三相断开。示波器为 DS100，普通探头地夹接板上 GND。照片中的 STOP 菜单是拍照时的查看设置，不单独证明原始采集设置。
