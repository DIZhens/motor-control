# 有限静止坐标电流环

本入口在现有 PWM 20 kHz／采样与计算 10 kHz 时序下，使用真实电流反馈和已有
`current_controller` 验证负反馈与电流跟踪。控制坐标系明确固定为 αβ：恒等 Park 变换，
不使用或伪造转子电角零位、极对数和方向标定。它不等同于转子 FOC 或速度闭环验收。

## 电流方向与幅值

本板名义换算的正方向为 Shunt+→GND；电机相电流规定桥→电机为正。
因此先扣冻结的名义零偏，再将实测 B、C 同时取反，最后重构 A 和 Clarke。
依据为原始网表及 [物理相映射修正后的静态对照](evidence/pwm-phase-mapping/summary.json)：
正α下 B/C 名义值同正、正β下 B负/C正，均与电机电流约定相反。
这足以确认符号，不能确认名义增益的绝对精度。

Observe 的 `signed_gain={1,-1,-1}` 使用同一方向约定；其零偏统计及诊断原始值继续保留
校正前的名义值。正式 `control.enabled`、电流增益和电角标定确认保持关闭。
本次不再以独立电流源未到为由重复方向检查，也不把精度待测写成方向未知。

## 单次试验边界

- 默认目标 α=+0.06、β=0 名义 A；目标矢量模长仅允许 0.01～0.08 A。
- 实际 enable 后 0.5 s 升流、2 s 保持、0.5 s 降流，然后 safe-off。
- Kp=0.5 V/A、Ki=10 V/(A·s)、回算系数50/s、积分限值0.3 V，属于保守试验参数，
  尚未按实测绕组电感整定。使用现有双轴 PI，不新增速度环。
- 调制电压比固定为0.4/14；允许母线10～14 V，因此算法电压请求矢量不超过0.4 V。
  这不是对死区、器件压降或实际端电压精度的保证。
- 校正方向后的实测 B/C 及重构 A 任一绝对值达到0.25名义A时立即关断。
  它是辅助阈值，未完成独立增益标定，不能等同于真实硬件保护门限。
- 复用两拍中性预装载再使能、同启动4096点真实关断零点、采样间隔与观测新鲜度检查，
  以及 TIM6 独立3.5 s总期限／125 µs采样心跳监视。失效不自动重试、清故障或恢复使能。
- 最后0.5 s保持窗口保存5000个连续样本的αβ均值、电压请求均值、误差峰值；
  主机只读冻结结果，不用零散SWD读数冒充连续采集。

台架新增命令17，独立8字节 `CurrentHoldConfig` 和84字节 `CurrentHoldSnapshot`；
旧邮箱20字节、旧快照184字节、命令15/16的参数及结果语义保持不变。
错误码18沿用有限试验独立超时、21沿用计算拒绝；只有正常轨迹完成才返回1。
快照是ADC单写者；ADC停止时须另外核对独立stop_reason和实际MOE，不能沿用旧active。

## 操作与工具

先在 OUTPUT 关闭、VBUS放电低于1 V后切为单独逻辑3V3，安装默认关断候选。
电机和编码器接线可保留，无外部注入。安装后只读核对镜像与默认关断；随后在OUTPUT
关闭时断开ST-Link的3V3，保留SWD/GND，固定空载电机；命令17使用原12 V／0.10 A，
命令18的定向包络使用12 V／0.20 A。
现场确认正常后采本启动零点，自动检查通过即发送一次默认3秒请求；无需手持仪器，不另留准备倒计时。
本入口仍通过SWD邮箱，不是VOFA启停接口。操作者可用OUTPUT立即停机，带电期间不暂停CPU。

```powershell
.\.venv\Scripts\python.exe -B -X utf8 firmware/targets/BLDC_G431/validation/tools/current_hold_once.py --output <新候选目录>
.\.venv\Scripts\python.exe -B -X utf8 firmware/targets/BLDC_G431/validation/tests/verify_current_hold_tool.py
.\.venv\Scripts\python.exe -B -X utf8 firmware/targets/BLDC_G431/validation/tests/verify_model.py
```

默认只离线冻结HEX/AXF/MAP、源文件和DWARF布局；`inspect`只读，`zero`仅采真实关断零点，
`execute`须提供候选、本启动零点锚、现场接线确认与母线实测参考，才可写入唯一命令17。
完整payload读回匹配后才提交sequence；失败只允许一次SAFE_OFF，没有烧录、复位或重启路径。
命令15/16工具不因本入口而扩大写入能力。

跟踪筛选比较均值矢量误差≤0.01名义A、保持窗口误差峰值≤0.03名义A。
正常完成、跟踪筛选和实物增益精度是三个不同结果，不自动安装标定或开放正式Motor RUN。

## 有限电流磁场往返

命令18复用原PI增益，定向目标默认0.4名义A，允许0.01～0.5 A；积分限值1.5 V、
调制电压比上限1.8/14、名义相电流辅助撤销阈值0.65 A。允许母线10～14 V，整个范围内
调制请求不超过1.8 V；12 V时比例上限对应约1.543 V。命令17仍为原0.01～0.08 A、
积分0.3 V、调制0.4/14及0.25 A撤销阈值，不扩大其包络。

目标依据[电机资料](../../../../hardware/actuators/2804-mt6701/README.md)的标称0.5 A及现有
约3.1 Ω相等效电阻粗测选择，供应商电流口径和实际增益仍未独立确认。按三相正弦电流
幅值0.4 A估算，IR约1.24 V、铜耗约0.744 W，因此补足积分/电压余量并将电源设为
12 V／0.20 A。它是一次五秒定向试验的参数依据，不是连续额定能力验收。

单次五秒：0.5秒升流、零角保持1秒、0.5秒移出完整一电角圈、保持1秒、
0.5秒返回零角、保持1秒、0.5秒降流关断；独立期限5.5秒、心跳125 µs。
本包络用于提高励磁后的单次对照；原位置稳定、回程、offset及极对数比例门限保持，
不预先保证消除机械回差。需要操作者确认本包络和供电条件后才发送功率命令。

PI坐标系随**施加磁场**方向变化，目标d为励磁电流、q为零；它不使用编码器角度闭环，
不把该坐标系当成已经标定的转子DQ。旋转坐标让保持的电流积分随磁场方向变化，避免
用原静止坐标的低带宽PI直接追踪2 Hz正弦目标。三角计算使用已有软件后端，不新增外设。
编码器只提供观测与新鲜度检查；正式Motor、标定安装及RUN许可不变。

新增独立8字节 `TargetValidationCurrentSurveyConfig`，以名义A提供励磁幅值，
`excursion_turns`必须为1。独立168字节 `TargetValidationCurrentSurveySnapshot`
记录三个保持段末尾250 ms内的新SSI窗口，头字段使用 `current_reference_a`，单位不与
命令16的 `voltage_v` 混用。窗口仍用原稳定、回程、offset与双向极对数比例筛选。
命令17原参数、84字节结果及三秒语义不变；命令18复用该84字节电流统计，采样/使能
计数为50002/50001，三个保持窗口共7500个10 kHz样本，均值目标α=励磁幅值、β=0。
每个保持角为零或完整一圈，因此可以合并均值；峰值误差涵盖全部三个电流窗口。
位置与电流筛选分别保存，只有二者通过才标记联合筛选通过，仍不自动确认或安装标定。
命令18的电流功能初筛采用均值误差≤max(10 mA,目标的5%)、保持误差峰值≤max(30 mA,
目标的12.5%)；0.4 A时为20/50 mA，兼顾原ADC噪声量级与早期保持窗口的有限建立过程。
低幅值仍沿用原10/30 mA，命令17门限不变。功能初筛不同于0.65 A关断阈值和绝对电流精度。
主机清单版本为2，冻结上述包络及依赖工具身份，连接前拒绝旧候选清单。

```powershell
.\.venv\Scripts\python.exe -B -X utf8 firmware/targets/BLDC_G431/validation/tools/current_survey_once.py --output <新的候选目录>
.\.venv\Scripts\python.exe -B -X utf8 firmware/targets/BLDC_G431/validation/tests/verify_current_survey_tool.py
```

工具默认离线，实际请求仍须显式动作、同启动零点、现场确认、镜像身份核对，参数读回后
仅提交一次命令18。主机等待上限8秒；失败只允许一次SAFE_OFF，不自动重试或重新使能。
离线R/L替身验证电流计算，SSI位置按预设轨迹提供，不是机械负载模型；不能代替实物位置
收敛、绝对电流精度、完整IRQ或WCET验收。

## 有限转子 DQ 电流环

命令19使用已通过完整电角圈初筛的7极对、编码器正方向与零位候选，读取真实SSI位置，
执行Id=0、带符号Iq的有限试验；不是继续转动预设磁场。候选证据随HEX/AXF/MAP冻结，
主机核对原映射门限和证据哈希后，逐次通过独立8字节 `RotorCurrentConfig` 传入Iq与零位。
目标允许正负0.01～0.2名义A，首轮±0.10 A；不修改正式Motor配置或持久标定。

采用既有PositionEstimator、ElectricalAngle和CurrentController。仅在新的SSI观测上按真实
时间差更新速度，两份有效观测建立速度后，才执行两拍中性stage/enable；重复时间戳下位置
变化、时间回退、未来或超过1.5 ms年龄的观测均撤销。每拍将位置分别预测到同步电流采样时刻
和电压作用参考时刻，再执行电流Park、PI及独立角度的inverse Park/SVPWM。
施加参考显式取sample后125 µs，即当前目标75 µs更新边界加100 µs保持区间的一半；
这是装配模型，不冒充实测精确延迟。20 kHz PWM、10 kHz计算与约1 kHz SSI节拍保持。

转子模式Kp=0.5 V/A、Ki=300 V/(A·s)，积分限值1.5 V、回算50/s。静态Ki=10在带反电动势
的短时模型中建立不足，因此只对命令19调整Ki；按约3.1 Ω相等效电阻对应十余Hz闭环量级，
实际电感、动态带宽及稳定裕度仍须实物验证。沿用1.8/14调制比例和0.65名义A辅助撤销阈值，
不扩大此前供电及电压包络；命令17/18保持原增益和行为。

单次1秒：0.2秒升流、0.6秒保持、0.2秒降流关断；独立总期限1.5秒、采样心跳125 µs。
机械速度绝对值上限300 rpm、累计净位移绝对值上限2圈，触界返回23并关断，不能标为正常
轨迹完成。操作者确认固定空载、原接线和12 V／0.20 A后，采本启动4096点零点，前检通过
直接发送一次请求；正反向可复用同一镜像，不自动重试、清故障或重启。

独立96字节 `RotorCurrentSnapshot` 以偶数sequence发布，保存DQ统计、运动和关断原因，
不改变命令17的αβ结果ABI。保持末尾0.6～0.8秒共2000点；正常完成采样/使能计数为
10002/10001、stage10001、enable1。电流初筛为DQ均值矢量误差≤10 mA、窗口误差峰值≤30 mA，
方向初筛要求净位移与Iq同号且超过0.003机械圈；两项分别保存，不把运动方向当作电流精度。
模型中机械位置为外部给定，包含独立延迟R/L和反电动势；它验证计算链，不证明实物转矩、
惯量、速度环或机械全圈标定。

```powershell
.\.venv\Scripts\python.exe -B -X utf8 firmware/targets/BLDC_G431/validation/tools/rotor_current_once.py --output <新的候选目录>
.\.venv\Scripts\python.exe -B -X utf8 firmware/targets/BLDC_G431/validation/tests/verify_rotor_current_tool.py
```

工具默认离线；显式zero只采零，execute只提交一次命令19，stop只提交一次SAFE_OFF。
带符号Iq与候选零位的payload读回一致后才提交sequence，主机等待上限4秒；错误仅补一次
SAFE_OFF。正常完成、运动边界停机、电流跟踪、方向判断和正式FOC验收分别记录。
提前停机未取得完整2000点窗口时，电流误差及跟踪结论记为null（未测），不得把初始化零值
当作实测反馈，也不能将其解释为100 mA误差或跟踪失败。
