# Hardware

本目录保存控制板硬件事实、电机与编码器参考资料，以及跨板卡使用的台架仪器信息。

| 入口 | 内容 |
| --- | --- |
| [BLDC_G431](BLDC_G431/README.md) | 自研 BLDC_control V1 控制板的硬件基线、设计与原始文件 |
| [ODRIVE_V36_405](ODRIVE_V36_405/README.md) | 第三方 STM32F405 驱动板的硬件资料 |
| [2804 电机与 MT6701 编码器](actuators/2804-mt6701/README.md) | 用户提供的商家参数、装配图与编码器板资料 |
| [台架仪器与配件](bench/README.md) | 电源、示波器、万用表、调试器及负载配件的型号和测量边界 |

板级目录记录 MCU、功率级、采样、接口、保护链、引脚和硬件边界；执行器目录保留资料来源与参数口径。商家标称、设计值和实物验证结果须分别记录。

硬件目录不承担 Motor 业务语义或 Host/Protocol 设计；固件标定与台架验证以对应目标的记录为准。
